## TIC Data Platform Subscriptions
The CLI interacts with the official TIC business intelligence API ([tic.io](https://tic.io)). Data subscriptions and query quota are managed directly by TIC:
- **API Access**: Requires an API key from TIC.
- **Data Coverage**: Swedish corporate registries, beneficial ownership, debtor summary, vehicle registry, bankruptcy records, and intelligence anomalies.
- **Pricing Tiers**: Commercial data packages and volume tiers are provided by TIC.

For official platform subscription details and data plans, visit [https://tic.io](https://tic.io).
